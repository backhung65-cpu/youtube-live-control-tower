# 🔴 유튜브 모바일 라이브 PC 통합 관제탑 (YouTube Live PC Control Tower)

> 스마트폰의 고화질 카메라로 유튜브 라이브를 송출하면서, **PC에서 방송 생성·예약·섬네일 실시간 제작 및 업로드·방송 프리셋 관리·실시간 송출 상태를 총괄 제어**할 수 있는 올인원 컨트롤타워 웹 대시보드 애플리케이션입니다.

---

## ✨ 핵심 기능 (Key Features)

### 1. 🎛️ 실시간 방송 관제탑 대시보드 (Command Center)
- **실시간 방송 상태 감지**: `🔴 LIVE 송출중`, `🟡 방송 대기중`, `⚪ 방송 종료` 상태를 한눈에 모니터링
- **방송 경과 시간 타이머**: 라이브가 시작되면 초 단위로 실시간 경과 시간(HH:MM:SS) 자동 카운팅
- **실시간 통계 모니터링**: 실시간 시청자 수, 좋아요 수, 스트림 연결 품질(Good) 표시
- **원클릭 방송 제어**:
  - `유튜브 시청 페이지`: 새 탭에서 내 라이브 방송 즉시 확인 (`https://youtube.com/live/{id}`)
  - `제목/설명 실시간 수정`: 방송 도중에도 제목과 설명, 공개 설정을 즉시 변경
  - `방송 종료 (End Stream)`: 클릭 한 번으로 안전하게 방송 종료
- **실시간 채팅 시뮬레이터**: 실시간 시청자 댓글 흐름 확인 및 운영자 공지 댓글 작성

### 2. 📱 스마트폰(유튜브 공식 앱) 원터치 송출 연동
- 복잡한 PC 카메라 캡처 보드나 케이블 연결 없이, 스마트폰의 **공식 YouTube 앱**을 그대로 활용합니다.
  1. **PC**: 방송 제목, 설명, 섬네일 등록 후 예약 생성
  2. **핸드폰**: 유튜브 앱 하단 `+` 버튼 > `실시간 스트리밍 시작`
  3. **핸드폰**: 오른쪽 상단 `📅 (달력/예약)` 아이콘 터치 > PC에서 만든 방송 선택
  4. **송출 시작**: `[라이브 스트리밍 시작]` 누르면 즉시 고화질 카메라 생방송 시작!
- **스마트폰 빠른 확인 QR코드** 생성 지원 (카메라로 QR 스캔 시 해당 라이브로 바로 이동)
- 대안으로 **PRISM Live Studio** 또는 **Larix Broadcaster** 앱을 위한 RTMP URL 및 스트림 키 제공

### 3. 🎨 16:9 유튜브 표준 섬네일 스튜디오 (Thumbnail Canvas Studio)
- 포토샵이나 미리캔버스 없이도 **1280x720 HD 해상도**의 고품질 섬네일을 1초 만에 완성
- **예배/모임 맞춤형 디자인 프리셋 템플릿**:
  - 🌌 미드나잇 네이비 (모던 클래식 대예배)
  - 🍷 버건디 와인 (경건하고 따뜻한 예배)
  - 💜 딥 퍼플 글로우 (뜨거운 찬양/성령집회)
  - 👑 골드 앰버 (특별 행사/부흥성회/기념식)
  - 🌿 에메랄드 숲 (청년부/찬양/힐링)
  - 🖤 미니멀 옵시디언 (심플 다크 모던)
- **자유로운 커스텀 기능**:
  - 메인 타이틀 (설교/행사명, 폰트 크기, 외곽선 강조, 입체 그림자 효과)
  - 서브 타이틀 (성경 본문/주제 구절)
  - 설교자/강사 및 날짜 시간 태그
  - 상단 뱃지 (`LIVE 생중계`, `주일 대예배` 등)
  - 배경 사진 불러오기 (예배당, 강단, 성도 사진 업로드) + **글자 가독성 어둡기 필터** 슬라이더
  - 교회/채널 투명 로고(PNG) 업로드
- **원클릭 기능**:
  - `PNG 고화질 다운로드` (1280x720)
  - `현재 방송 섬네일로 즉시 적용` (유튜브 API를 통해 방송 섬네일 즉시 교체)
  - `이 섬네일로 방송 개설`

### 4. 📋 방송 프리셋 매니저 (Preset Manager)
- 매주 반복되는 주일 대예배, 수요 기도회, 금요 철야기도회 등의 메타데이터를 템플릿으로 저장
- **자동 치환 태그 지원**:
  - `{DATE}`: 오늘 날짜 (YYYY.MM.DD)
  - `{설교제목}`, `{성경본문}`, `{설교자}`
- 프리셋에서 클릭 한 번으로 방송 개설 폼에 모든 내용이 1초 만에 자동 채워집니다.

### 5. ⚙️ 데모 모드 (Demo Mode) & Google Cloud API 연동
- **기본 데모 모드 탑재**: Google Cloud API 키가 없어도 모든 대시보드, 섬네일 제작실, 프리셋 관리, 방송 상태 전환 및 시뮬레이션을 100% 즉시 체험 가능
- **Google Cloud Console 가이드**: 실제 유튜브 채널과 연동할 수 있도록 OAuth 2.0 Client ID 발급 5단계 상세 안내 내장
- **데이터 백업 및 복원**: 작성한 프리셋과 방송 설정을 JSON 파일로 백업/복원 지원

## 🚀 실행 방법 (Getting Started)

### 1. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속 시 바로 관제탑 화면이 열립니다.

### 2. 프로덕션 빌드
```bash
npm run build
```
`./dist` 폴더에 최적화된 프로덕션 빌드 결과물이 생성됩니다.

### 3. 빌드 미리보기
```bash
npm run preview
```
